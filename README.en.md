# Brownian Motion Simulation with Next.js and p5.js

> *The code was optimized with AI tools!*

This project is an interactive simulation of Brownian Motion, implemented with [Next.js](https://nextjs.org/) and [p5.js](https://p5js.org/). The goal is to understand and visualize Brownian Motion, a fundamental concept in physics, through programming and to foster my interest in physics.

## Motivation

I started this project to deepen my knowledge of physics through programming. I was particularly inspired by a quote from Stanford Professor **Chris Piech**:

> "When people learn to code they start doing better in other subjects."  
> [YouTube Link](https://youtu.be/3mRvCF4qyTA?si=rrMr_ZYwngLw7rnu)

With custom visualizations, complex physical processes become more understandable and even fun!

## What is Brownian Motion?

Brownian Motion describes the random movement of particles, such as pollen on water, caused by collisions with the molecules of the liquid. This behavior can be simulated and observed with computer code.

## Why these technologies?

For this project, I chose **Next.js** and **p5.js**:

- **Next.js** is excellent for modern web applications as it's React-based and enables rapid development and easy deployment.
- **p5.js** is a creative JavaScript library that's perfect for visual and interactive simulations. It offers many functions to easily create animations and graphics – ideal for physical experiments in the browser.

Although I normally enjoy working with **TypeScript**, I deliberately chose **JavaScript** here because the type definitions for p5.js are sometimes incomplete or inaccurate. With JavaScript, the integration is more straightforward, and the focus is on creative experimentation and visualization.

## Project Details

- **Technologies:**
  - Next.js (React-based web framework)
  - p5.js (Creative JavaScript library for visual simulations)
- **Features:**
  - Interactive temperature control (influences particle movement)
  - Visualization of particle collisions at the edges
  - Intuitive color gradients based on "temperature" and activity
  - Multilingual support (German/English)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the simulation.

## Languages

This project supports both German and English. Use the language switcher in the top-right corner to change the interface language.
